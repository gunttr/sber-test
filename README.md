# Документация к тестовому

## Зачем nginx

Я решил добавить nginx, чтобы можно было проверить на условие прокси из ТЗ. Можно и просто подделать заголовки `X-Forwarded-For`.

## Запуск приложения

```bash
docker compose up -d
```

## Запуск тестов

Сначала нужно установить тестовое окружение. Используемая при разработке версия питона - **`3.14`**. Совместима с **`3.13`**. Остальные не проверял

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
```

Чтобы заработали интеграционные тесты (тесты для редиса), нужно предварительно развернуть приложение (или редис отдельно). В данном примере разворачивается приложение

```bash
docker compose up -d
```

Запуск тестов

```bash
python3 -m pytest -v
```
